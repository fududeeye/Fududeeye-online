# Fududeeye Online — Ready for GitHub / Render

This package is prepared for deployment as one Node/Express web service.

## Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Health check: `/health`

The app uses the same Render origin for API calls when hosted, so the frontend cannot accidentally use an old saved API URL.

For direct `content://` / `file://` opening on a phone, the verified API fallback is:
`https://fududeeeye-online.onrender.com`

## Environment variables
Set a strong `ADMIN_PASSWORD` in Render. `JWT_SECRET` and `PAYMENT_WEBHOOK_SECRET` can be generated by Render.

## Important
Real Zaad/eDahab automatic payment verification is not included without an official provider API/webhook. Do not use fake SMS/OTP or scraping.
